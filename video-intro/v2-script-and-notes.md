# ALPHA intro V2 — brighter, faster, more visual

32 seconds · 1920 × 1080 · 30 fps · silent draft

V2 replaces the fixed dark panel layout with a bright studio, closer presenter shots, small body turns, varied Mixamo gestures, camera pushes, floating course covers, three rotating 3D characters, and six map cuts. The first version remains available for comparison.

Shot markers: **1, 121, 271, 451, 661, 781, 871**. Maps change at frames **451, 486, 521, 556, 591, 626**.

The Mixamo action is on **V2 | ALPHA Mixamo**. The V2 collections group the studio, presenter, editable motion graphics, and 3D model lineup. All titles are native Blender text. The 3D model lineup uses the actual website ALPHA, Beesto, and Luna model files. The maps use animated planes with the website's existing product imagery; full 3D map scenes were not imported. Textures and fonts are packed.

The project is configured for a final PNG frame sequence in `video-intro/v2-frames/`. The proxy render script changes frame timing in memory only. No voiceover, music, or lip sync has been added, and no website files have been changed or published.
